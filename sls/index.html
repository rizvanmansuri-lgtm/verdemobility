PLATFORM ARCHITECTURE OVERVIEW

From design tool to display, in three layers

Design the screens on a PC, run them on in-house compute hardware, and show them on whatever display the application calls for.

Design Tool

PC-based drag-and-drop UI design

Build screen flow and configure widgets visually — gauges, charts, buttons, icons — without writing firmware for every new product line.

  • Visual screen-flow and widget configuration
  • Deploy custom HMI screens straight from a PC
Compute Hardware

In-house compute board, industrial I/O

An in-house compute board running embedded Linux, with the industrial I/O real deployments need already on the board.

  • RS-485, RS-232, UART, and CAN on board
  • USB, Ethernet, and SD card storage included
Display Interface Layer

Screen-size agnostic, 3.5" to 55"+

The same platform scales from a handheld panel to a wall-mounted kiosk display, with or without capacitive touch.

  • Capacitive touch or non-touch displays
  • Phone-size panels through 55"+ kiosk screens
